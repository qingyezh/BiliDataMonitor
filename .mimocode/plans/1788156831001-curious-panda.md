# BiliDataMonitor Linux 适配计划

## 目标
将项目完整复制到 `D:\Desktop\program\preoject\BiliDataMonitor-linux`，适配 Ubuntu 24。

## ⚠️ Node.js 版本警告
Ubuntu 24 默认 Node.js 为 18.x，**不支持** `--experimental-sqlite`（需 Node 22+）。建议安装方式：
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
```
后续 systemd service 文件将使用 `process.execPath` 动态获取 node 路径。

---

## 实施步骤

### 阶段 1：复制与清理
1. 完整复制项目到 `BiliDataMonitor-linux`
2. 删除 Windows 专属文件：`scripts/autostart.vbs`、`scripts/start.bat`、`scripts/stop.bat`
3. 删除 `src/tray/Cargo.lock`（让 cargo 重新生成 Linux 版本）

### 阶段 2：Rust 托盘适配

**`src/tray/Cargo.toml`** — 替换依赖：
- 删除 `winapi = { version = "0.3", features = ["winuser"] }`
- 添加 Linux 条件依赖：
  ```toml
  [target.'cfg(target_os = "linux")'.dependencies]
  libappindicator = "0.9"
  gtk = "0.18"
  ```

**`src/tray/src/main.rs`** — 替换 4 个函数 + 添加 GTK init：
- `http_get`：`powershell Invoke-WebRequest` → `curl -s -o /dev/null -w "%{http_code}"`
- `open_browser`：`cmd /c start` → `xdg-open`
- `trigger_refresh`：`powershell Invoke-RestMethod` → `curl -X POST`
- `shutdown_server`：同上
- `main()`：添加 `#[cfg(target_os = "linux")] gtk::init().unwrap();`

**系统依赖**：
```bash
sudo apt install -y libayatana-appindicator3-dev libgtk-3-dev pkg-config
```

### 阶段 3：后端适配

**`src/server/routes/system.ts`** — 跨平台自启动：
- `isAutostartEnabled()`：Linux 分支用 `systemctl --user is-enabled bili-monitor.service`
- `enableAutostart()`：Linux 分支生成 systemd user service 文件到 `~/.config/systemd/user/`，执行 `daemon-reload` + `enable`
- `disableAutostart()`：Linux 分支执行 `disable` + 删除 service 文件

**`src/server/index.ts:74`** — 浏览器打开：
- 添加 `linux` 分支使用 `xdg-open`

### 阶段 4：前端适配

**`src/frontend/src/views/Settings.vue:74`**：
- "Windows 开机自启动" → "开机自启动"

### 阶段 5：新建 Shell 脚本与 Service

**`scripts/start.sh`**（新建）：
- `lsof -ti:8123` 查找旧进程（按 cmdline 过滤本项目）
- `nohup node --experimental-sqlite src/server/dist/index.js &`
- 可选启动 `app/tray`

**`scripts/stop.sh`**（新建）：
- 按端口停止后端
- `pkill -f "bili-monitor-tray"` 停止托盘

**`bili-monitor.service`**（新建，模板文件）：
- systemd user service，`WorkingDirectory` 使用 `%h/BiliDataMonitor-linux`
- `ExecStart` 使用当前 node 路径 + `--experimental-sqlite`
- `Restart=on-failure`

设置权限：`chmod +x scripts/start.sh scripts/stop.sh`

### 阶段 6：验证
1. `pnpm install && pnpm build` — 前后端构建
2. `cargo build --release`（在 src/tray 下）— Rust 托盘编译
3. 启动后端验证健康检查
4. 托盘图标显示与菜单功能
5. systemd 自启动开关测试
